# AntiGravity: The Cinematic Voting Journey

AntiGravity is a premium, immersive web experience designed to guide first-time voters through the emotional and practical journey of their first election. Built with a focus on high-end aesthetics, cinematic pacing, and helpful AI guidance.

## ✨ Features

- **Cinematic Narrative:** A scene-based interactive story that flows like a premium product reveal.
- **AI Voting Guide:** An independent, built-in AI assistant powered by Google Gemini, strictly focused on voting and civics.
- **Dynamic Animations:** Staggered text reveals, neural-network backgrounds, and Lottie animations.
- **Smart Registration Flow:** A calm, step-by-step detour that demystifies the voter registration process.
- **Misinformation Awareness:** An interactive scenario teaching users to identify and avoid common voting scams.

## 🛠️ Tech Stack

- **Core:** Next.js (App Router)
- **Logic:** TypeScript
- **Styling:** Vanilla CSS (Cinematic design system)
- **Animations:** Framer Motion & Lottie Player
- **AI:** Google Generative AI (Gemini SDK)

## 🚀 Getting Started

### 1. Prerequisites
- Node.js installed
- A [Google AI Studio API Key](https://aistudio.google.com/app/apikey)

### 2. Setup
Clone the repository and install dependencies:
```bash
npm install
```

### 3. Environment Variables
Create a `.env.local` file in the root directory and add your Gemini API key:
```env
GEMINI_API_KEY=your_actual_api_key_here
```

### 4. Run Locally
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to start the journey.

## 🎨 Design Philosophy
The experience is designed to feel **calm, immersive, and intentional**. It uses a deep dark gradient palette (deep blue → purple → black) with soft glowing highlights and minimal UI to ensure the focus remains on the message: *Your vote is your voice.*
